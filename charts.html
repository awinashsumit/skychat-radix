Charts

Four shapes, one hue. Magnitude is always carried by shade of the brand amber, so the charts stay on brand and stay readable for anyone who cannot separate hues. Markup comes from charts.js, styling from dashboard.css, palette from tokens.css.

The ramp
The 12-step accent scale cannot do this job. It is tuned for UI states and is not monotonic in contrast — --accent-9 is lighter than --accent-8 — so a reader could not tell which shade means more. These six climb steadily in both themes.
Charts
Area One series over time. Hover for the number.
Chart.area({ labels, values, valueLabel: 'Active learners' })
Area, with a target A baseline above zero, only because the reader knows the scale.
Chart.area({ labels, values, min: 80, max: 100, target: 95 })
Heatmap Two categories, one value. The shade is the whole message.
Chart.heatmap({ rows, cols, values })   // null cell = no data, not zero
Donut Parts of one whole. Three or four slices, never nine.
Chart.donut({ segments, label: 'Total learners' })
Bars Ranked. Sorting plus length answers “where is it worst”.
Chart.bars({ items: [{ n, v, label }] })
When not to use the ramp

The ramp encodes ordered magnitude. For unordered categories — Desktop against Mobile, one course against another — there is no “more”, so shade would imply a ranking that does not exist. Use the categorical palette --chart-1 … --chart-8 for those, and keep it to four or fewer.
